Construction & Renovation Website

A fully responsive business website for a premium construction and renovation company. The site showcases kitchen remodels, bathroom upgrades, and whole‑home renovations. Features include a project gallery, client testimonials with star ratings, team profiles, FAQ accordion, contact form with rating system, and clear calls‑to‑action for free consultations and quotes. Built with modern HTML5, CSS3, Bootstrap 5, FontAwesome icons, and JavaScript for interactivity.

Client: BuildMaster Renovations (Portfolio Project)
Type: Web Development / UI Design
Year: 2025
Built as a self-directed portfolio piece to demonstrate a complete, production-quality business site — gallery, testimonials, team profiles, FAQ, and a rating-integrated contact form — end to end.
